# The Autobiography of Abir Arafat Chawdhury

My personal autobiography website — my life told in my own words, across 21 stories: public speaking, the silence behind my personality, the battles nobody sees, code, football, family, faith and the future I am building.

## Features

- Home page with my introduction, skills, projects, photo gallery and story previews
- A separate page for every life story, with chapter headings, photos and previous / next navigation
- An "All Stories" library with search and theme filters
- A live daily visits dashboard
- Light and dark themes
- Works on phones, tablets, laptops and large screens

## Tech stack

- React 19 + TypeScript
- TanStack Start and TanStack Router
- Tailwind CSS v4
- Vite
- Supabase (visitor counter)
- Vitest (tests)

## Run locally

You need [Bun](https://bun.sh) (or Node.js with npm).

```sh
bun install
bun run dev
```

Other commands:

```sh
bun run build   # production build
bun run test    # run the tests
bun run lint    # lint the code
```

## Deployment

Pushing to `main` builds and deploys the site to GitHub Pages through `.github/workflows/deploy.yml`.
